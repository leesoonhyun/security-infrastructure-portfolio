# Disclosure & Publication Policy

## 목적

이 저장소는 채용 포트폴리오와 학습 기록을 위한 공개 문서입니다. 보안 실습의 재현성을 유지하면서도 실제 사용자·서비스·팀원·저작권자의 권리를 침해하지 않는 것을 원칙으로 합니다.

## 공개 등급

### A. 전체 공개

- 본인이 만든 설명·표·도식·점검표
- VulnHub 등 공개·의도적 취약 VM의 풀이, 명령, flag
- 본인/팀이 소유하고 공개가 허가된 격리형 CTF의 풀이
- localhost·예시 IP를 사용한 방어 설정과 검증 코드

상세 풀이에는 `Spoiler`와 `Authorized lab only`를 표시합니다.

### B. 비식별화 후 공개

- 팀 프로젝트의 본인 역할과 통합 결과
- 사설 IP, 실습 계정, 호스트명이 포함된 화면
- 웹셸·권한 상승 흐름: 허가된 VM임을 밝히고 실제 외부 대상에 적용하지 않음
- 개인 과제의 핵심 화면: 강의 템플릿과 개인·계정정보를 제거

### C. 목록·요약만 공개

- ISO·OVA·VMDK·취약 서버 이미지
- 교육기관·강사 제공 교안
- 팀 공동 보고서·발표자료
- 제3자 참고 보고서·이미지

### D. 비공개

- 실제 사이트의 PHPSESSID, JWT, API Token, Cookie, 인증 헤더
- 개인·팀원의 비밀번호, SSH private key, 인증서 private key
- 전화번호, 주소, 생년월일, 군번, 문서 식별번호
- 실서비스나 허가되지 않은 대상의 취약점·접근정보
- 악성코드 원본과 실행 가능한 샘플

## 공개 가능한 flag와 세션의 차이

VulnHub의 flag는 의도된 퍼즐의 정답이며 스포일러 표시 후 공개할 수 있습니다. 반면 세션값·토큰은 계정의 인증수단입니다. 대상이 교육 사이트라도 공개 노트에는 값 자체를 남기지 않고 `<LAB_SESSION>`으로 대체합니다.

## 공격 명령 공개 기준

다음 조건을 모두 충족할 때만 상세 명령을 게시합니다.

1. 대상이 본인 소유 또는 명시적으로 공격을 허가한 교육용 환경
2. 문서 상단에 범위·출처·격리 방식 표시
3. 실제 공인 IP·운영 도메인·개인 자격정보 제거
4. 원인·탐지·완화·재검증을 함께 기록
5. VM·악성파일·타인의 산출물은 배포하지 않음
